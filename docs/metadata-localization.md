# 장르와 태그 표시명

`ios/KavaReader/KavaReader/Models/MetadataLocalization.swift`에 한국어 표시명을 관리하고,
`Models/MetadataCategoryRegistry.swift`에서 언어와 무관한 분류 ID, 표시명과 별칭을 연결합니다.
Kavita, 파일 내장 정보, AniList와 사용자 입력이 같은 기준을 사용합니다.

- 알려진 이름은 `genre:fantasy`, `tag:school` 같은 ID로 비교합니다. `Fantasy`와 `판타지`는 같은 장르입니다.
- 새 커스텀 분류는 알려진 항목의 ID로 저장하고, 기존 문자열 저장본은 읽을 때 해석합니다. 원본 출처의 문자열과 서버 데이터는 유지합니다.
- 메타데이터 생성·디코딩·병합, 중복 검사, 홈 장르 탐색과 추천은 같은 ID를 사용합니다. 기존 일일 추천은 분류 알고리즘 버전 변경으로 재선정합니다.
- 알려진 항목은 선택한 언어로 표시합니다. 한국어로 입력한 `판타지`도 영어 설정에서는 `Fantasy`입니다.
- 미등록 사용자 정의 항목은 원문을 유지합니다. 대소문자, 연속 공백과 유니코드 정규화 차이는 정리하지만 부분 문자열이나 문장 전체를 번역하지 않습니다.
- 동의어는 명시적으로 등록합니다. 번역명이 같다는 이유로 서로 다른 분류를 합치지 않습니다. 입력에 여러 후보가 있으면 영문 이름을 함께 보여 선택하게 하며, 표시명이 겹치는 알려진 항목도 영문 이름으로 구분합니다.
- 장르와 태그의 ID는 별도로 구분합니다. 원본에 같은 분류가 있으면 중복 커스텀 항목을 숨기며 원본 색상과 출처를 유지합니다.

## 언어 확장

분류 목록의 각 `Entry.localizedNames`에 언어 코드를 키로 표시명을 추가합니다.
같은 목록에서 입력 별칭도 자동 등록하므로 새 언어의 입력을 인식하기 위한 별도 역번역표는 필요하지 않습니다.
분류 ID는 번역이나 UI 언어 변경과 무관하게 유지합니다. `Catalog`는 모든 언어의 이름을 조회하고,
동일한 번역명에 여러 분류가 대응하면 모든 후보를 반환합니다.
영어 원본 이름과 명시적인 저장 ID는 해당 분류를 직접 가리킵니다.
현재 앱 언어 선택은 한국어와 영어이며, 실제 언어 추가 시 `AppLanguage`와 앱 문구 번역도 함께 확장해야 합니다.

## 출처와 지원 범위

2026-10-01에 [AniList 공식 GraphQL API](https://graphql.anilist.co)에서 공개 태그 목록과
각 태그의 설명을 조회하고, 설명을 바탕으로 앱용 한국어 표시명을 작성했습니다.
공식 한국어 번역이나 외부 한국어 데이터베이스를 가져온 것은 아닙니다.
API 쿼리 정의는 [AniList 공식 문서](https://github.com/AniList/docs/blob/master/docs/reference/query.md)에 있습니다.

```graphql
query {
  MediaTagCollection {
    name
    description
    category
    isAdult
  }
  GenreCollection
}
```

확인 당시 AniList 태그 428개와 장르 전체를 지원합니다. 기존 Kavita용 이름과 별칭을 포함한
번역표는 총 484개입니다. 목록과 번역표 키를 대조해 누락과 중복이 없는지 정적으로 확인했습니다.
이후 추가되는 태그와 Kavita 사용자 정의 태그는 등록하기 전까지 원문을 표시합니다.

`Female Harem`과 `Male Harem`은 주인공의 성별이 아니라 주인공에게 호감을 갖는 인물들의
성별을 뜻하므로 각각 `여성 하렘`, `남성 하렘`으로 표시합니다.
`Football`은 `축구`, `American Football`은 `미식축구`입니다.
`Watersports`는 공식 설명상 성인 태그이므로 수상 스포츠로 번역하지 않습니다.

번역 범위를 갱신할 때는 위 쿼리로 최신 목록을 조회하고, 등록되지 않은 이름과 설명을 확인한 뒤
영어 이름의 소문자를 키로 추가합니다. 성인 태그를 포함해 같은 조회 규칙을 적용하며,
한국어 음역이 널리 쓰이는 용어는 음역으로 표시합니다.
