# Kava

Synology NAS에서 운영 중인 Kavita 서버의 만화를 iPad에서 탐색하고 읽기 위한 앱입니다. 첫 번째 연동 대상은 Kavita이며, 앱이 서버에 직접 연결합니다.

## 현재 상태

- SwiftUI 기반 iOS 앱이며 프로젝트 배포 대상은 iOS 26입니다.
- 서버 설정에서 **Kavita** 또는 **Kavita OPDS**를 선택합니다. Kavita에서는 서버 주소와 API Key를 입력하고, Kavita OPDS에서는 OPDS 주소를 붙여넣고 **OPDS 주소로 연결**을 누르면 서버 주소와 인증 키를 자동으로 채우고 연결을 확인합니다. 라이브러리, 작품 상세, 챕터, 페이지 이미지는 두 유형 모두 Kavita API에서 불러옵니다.
- Paperback이나 Kavya 익스텐션을 앱 안에서 실행하지 않습니다. Kavya/Paperback 사용 경험에서 확인된 Kavita API 흐름을 앱 코드에서 직접 구현합니다.
- 서비스 인터페이스는 있지만 현재 구현된 서버는 Kavita 하나입니다. 다른 서버 공급자는 아직 연결되지 않았습니다. 직접 가져온 CBZ·ZIP 파일은 로컬 파일 공급자로 읽습니다.

구조와 실제 구현 상태는 [docs/architecture.md](docs/architecture.md), [progress.md](progress.md), 다음 작업 후보는 [plan.md](plan.md)를 참고하세요.

## 직접 만화 추가

라이브러리는 **즐겨찾기 / Kavita / 파일**로 구분합니다. 파일 화면의 `+`에서 CBZ·ZIP 여러 파일 또는 폴더를 선택하면 앱 내부로 복사하고, 폴더별로 작품을 묶습니다. 작품을 길게 누르면 즐겨찾기, 권 추가, 파일 관리(이름 변경·작품 합치기·완독/초기화·용량 확인·삭제)를 사용할 수 있습니다. 홈과 검색은 두 출처를 함께 표시합니다.

가져온 만화는 서버 없이 오프라인으로 읽고 진행률을 기기에 저장합니다. iCloud 파일도 선택해 가져올 수 있지만 폴더 자동 연결·기기 간 동기화는 구현하지 않았습니다. 중복은 파일 내용으로 확인합니다. 가져오기를 중단하거나 앱을 다시 실행한 뒤 같은 폴더를 선택하면 완료된 파일은 건너뜁니다. ZIP의 저장/Deflate 압축만 지원하며 암호화·ZIP64·CBR·7z·PDF는 이번 파일 가져오기 대상이 아닙니다.

EPUB 파일 가져오기는 현재 지원하지 않습니다. 파일 선택, 폴더 가져오기와 권 추가는 CBZ·ZIP만 허용합니다.

장르·태그는 출처별로 읽습니다. Kavita 작품은 Kavita 정보를 우선하고, 파일 작품은 ComicInfo.xml 내장 정보를 우선합니다. 자동 AniList 연결은 기본 분류가 없을 때만 보완하며, 사용자가 직접 AniList 작품을 연결하면 해당 장르·태그를 최우선으로 사용합니다. 기존 파일도 내장 정보를 다시 읽으며, 홈 추천과 장르 탐색에서 두 출처를 함께 사용합니다.
